# オセロゲーム企画書

## 1. 基本情報

- **タイトル候補**：『手加減してあげる』／『煽セロ』
- **ジャンル**：対話・学習要素のあるオセロ
- **開発環境**：Unity
- **対応端末**：PC・スマートフォンを含む各種端末
- **公開方法の第一候補**：Unity WebGLによるブラウザ公開
- **提出期限**：2026年9月5日
- **現在の状況**：企画段階（未実装）

> 「今日はどれくらい手加減してほしい？」

---

## 2. 企画概要

生意気なAIと対戦できるオセロゲーム。

AIはただ石を置くだけではなく、プレイヤーが打った手を評価し、好手には渋々感心し、悪手には具体的なケチをつける。AIが劣勢になると、それまでの余裕が崩れて言い訳や動揺が増える。

ゲームとして楽しめるだけでなく、対局を通してプレイヤーがオセロを上達できる作品を目指す。

### 企画の特徴

- 盤面の状況に応じて反応する、生意気な対戦AI
- 「難易度」ではなく「手加減」を選ぶ設定画面
- 対局後に最大の悪手を振り返る学習機能
- 提出後に拡張できる、初心者脱却用の学習機能
- PCやスマートフォンから遊べるブラウザ対応

---

## 3. ゲームの基本ルール

基本ルールは通常のオセロに準拠する。

- 8×8の盤面を使用する
- 黒が先手、白が後手となる
- 相手の石を自分の石で挟める場所に石を置く
- 挟んだ相手の石を自分の色へ裏返す
- 石を置ける場所がなければパスとなる
- 両者とも置けなくなった時点で対局終了となる
- 最終的に石が多い側の勝利となる

### 基本のゲーム進行

1. タイトル画面を表示する
2. AIの「手加減」を選ぶ
3. 黒・白などの対局条件を選ぶ
4. AIと対局する
5. 勝敗を表示する
6. 対局中の最大の悪手を1つ振り返る
7. 再戦またはタイトルへ戻る

---

## 4. 生意気なAI

AIは同じキャラクターのまま、選択された「手加減」に応じて強さを変える。強さごとに人格を分けないことで、プレイヤーと一人のライバルとの関係を作る。

### 盤面に応じた反応例

| 状況 | セリフ例 |
|---|---|
| 悪手を打つ | 「そこ置くんだ。角、いらない派なんだね」 |
| 良い手を打つ | 「……まあ、偶然にしては悪くない」 |
| 同じ失敗を繰り返す | 「また角の隣。前世で角に恨みでもある？」 |
| AIが負けそうになる | 言い訳や動揺が増える |
| プレイヤーが逆転する | それまでの余裕が崩れる |

### キャラクター表現の方針

- 敵AIは人型ではなく、オセロの石をモチーフにした白黒の浮遊マスコットとする
- 大きなシアンの目、眉、口、耳状アンテナ、体の傾きによって感情を表現する
- PCとスマートフォンで同じ画像素材を使用し、端末に応じて表示サイズを変える
- 生意気ではあるが、本気で相手を傷つける発言はしない
- 煽りには盤面上の根拠を持たせる
- 良い手は渋々でも認める
- 優勢時、互角時、劣勢時で態度を変える
- セリフは短くし、対局のテンポを妨げない
- AIの顔と表情を表示し、文章だけでなく視覚的にも感情を伝える

### 表情の種類

通常時のアイドル状態に加え、対局中の状況に応じて5種類のリアクションへ切り替える。

| 表情 | 使用する状況 | 表現 |
|---|---|---|
| アイドル状態 | 発言や特別な反応がないとき | 半目と薄笑いで、静かな余裕を見せる |
| 得意げ | AIが優勢、またはプレイヤーを煽るとき | 冷笑的な目と控えめな笑み。記号は使わない |
| 呆れ・疑問 | プレイヤーが明確な悪手を打ったとき | 片眉を上げ、「？」または「……？」で理解できないふりをする |
| 渋々感心 | プレイヤーが好手を打ったとき | 感心を隠そうとする不満そうな表情。記号は使わない |
| パニック | AIが角を失う、逆転されるなど、余裕が完全に崩れたとき | 大きく見開いた目、汗、震え、「!!」を使用する |
| 敗北・強がり | AIの敗北時 | 垂れたアンテナ、不機嫌な目、ため息で悔しさを表す |

### 記号の使用ルール

- 通常のAIは常に冷笑的で、感情を大げさに表へ出さない
- 「？」は、悪手を理解できないふりをして見下す場面で使用する
- 「!!」は日常的な煽りには使用せず、AIが本当に動揺した場面だけで使用する
- セリフ内では感嘆符を多用せず、驚きは主に表情、汗、アンテナ、体の震えで伝える
- リアクション後は数秒でアイドル状態へ戻す

## 5. AIの「手加減」

最低3段階から選択できるようにする。表示上は「初級・中級・上級」や「難易度」という言葉を使わず、AIが手加減の程度を尋ねる形にする。

| 手加減 | 想定する強さ | 方針 |
|---|---|---|
| かなり手加減 | 初心者向け | 浅い読みと意図的なミスを含め、初心者にも勝機を作る |
| 少し手加減 | 経験者向け | 角、危険マス、可動域などを評価して安定して戦う |
| 手加減なし | 上級者向け | より深い探索を行い、終盤では可能な範囲で完全読みを使う |

表示例：

> どのくらい手加減してほしい？

- かなり手加減
- 少し手加減
- 後悔しても知らない

## 6. 提出版の学習機能

提出期限までに、対局後に「最大の悪手を1つ選び、よりよい手と理由を表示する」機能を実装する。

### 表示する内容

- 悪手を打った時点の盤面
- プレイヤーが実際に打った手
- AIが推奨する、よりよい手
- その手が悪手だった理由
- 改善につながる短い助言
- 盤面に合わせたAIの煽り

### 表示例

> 「本日のやらかしは、17手目のここ」

> 「石をたくさん取れて満足した？ 相手の置ける場所を増やしてるけどね」

> 「代わりにここへ打てば、相手の選択肢を2か所に絞れた」

煽るだけで終わらず、「何が悪かったか」「代わりにどうすればよかったか」を必ず示す。

### 悪手の判定案

各手について、プレイヤーの着手後の評価値と、その局面における最善手後の評価値を比較する。評価値の低下が最も大きかった手を、その対局の最大の悪手として扱う。

評価には、開発段階に応じて以下を使用する。

- 角の獲得
- X打ち・C打ちなど危険マスへの着手
- 自分と相手の着手可能数
- 確定石
- 辺の状態
- 終盤の最終石数

## 7. UI・操作

PCとスマートフォンの両方で操作できるUIを目指す。

### 想定画面

- タイトル画面
- 手加減選択画面
- 対局画面
- 勝敗結果画面
- 最大の悪手を確認する振り返り画面

### 操作方針

- PCではマウス操作に対応する
- スマートフォンではタップ操作に対応する
- 石を置けるマスを分かりやすく表示する
- 小さな画面でも押し間違えにくいサイズを確保する
- AIのセリフが盤面を隠さないようにする
- 画面の縦横比が変わっても崩れにくいレイアウトにする

### 敵AIの表示

敵AIは、白黒の浮遊マスコットのイラストと短い吹き出しを組み合わせて表示する。コンパクトな全身が収まる正方形画像を共通素材とし、盤面の操作領域を優先する。

- 通常時のセリフは1～2行に収める
- 長いセリフはタップまたはクリックで全文を表示する
- 過去の発言は会話履歴から確認できる構成を検討する
- 発言がない間はAI表示を小さくする
- 表情差分でAIの余裕や動揺を表現する

### 端末別レイアウト

| 画面 | 配置 |
|---|---|
| PC・横長画面 | 盤面の右側にAIのイラスト、吹き出し、石数などを表示する |
| スマートフォン・縦長画面 | 盤面の上側に「顔アイコン＋吹き出し」を横長に表示する |
| 感想戦 | 盤面を少し縮小し、AIの解説欄を通常より広くする |

スマートフォンでは、AIの存在感を残しながら盤面を可能な限り大きく表示する。AIの吹き出しが盤面へ重ならない構成を基本とする。

## 9. 今後の拡張案

学習機能の最終形は、次の3層構造とする。

1. **対局中は自力で考える**  
   通常は解説を表示せず、プレイヤー自身が考える時間を守る。

2. **必要なときだけ段階式ヒントを見る**  
   考え方、危険なマス、候補手、最善手の順にヒントを具体的にする。

3. **対局後に重要な3手を感想戦で復習する**  
   最大の悪手、最もよかった手、勝敗が動いた分岐点を振り返る。

### 初心者脱却チートシート（提出後に実装）

ルールを覚えたばかりの人が、初心者相手に安定して戦えるようになることを目標とする。情報を一度に詰め込まず、次の10段階に分けて読めるようにする。

1. **角は最優先**：角の石は二度と返されない。取れる角は確保し、相手には簡単に渡さない。
2. **角の隣は危険**：X打ちとC打ちは相手に角を渡す原因になりやすいため、慎重に打つ。
3. **序盤は取りすぎない**：一度に多く返すより、次に打てる場所を残す。
4. **相手の選択肢を減らす**：相手の着手可能数を減らし、行動を制限する。
5. **自分の選択肢を残す**：複数の候補手を持てる局面を目指す。
6. **辺は角ほど安全ではない**：角を取れないまま辺を広げる危険性を知る。
7. **確定石を意識する**：角から連続した辺など、終局まで返されない石を増やす。
8. **目先の石数より手番を考える**：終盤に自分が打てる場所を確保する。
9. **終盤は石数を数える**：空きマスが少なくなったら、数手先を具体的に比較する。
10. **偶数理論を知る**：空き領域の数と手番を意識し、最後に打てる形を目指す。

将来、感想戦の解説から関連するチートシート項目を直接開けるようにする。

そのほかの拡張候補：

- プレイヤーが自由入力でAIへ言い返す機能
- 固定選択肢と生成AIを組み合わせた会話
- 同じ失敗を記録し、次の対局で蒸し返す機能
- 実力に応じて強さを調整するライバルモード
- 詳細な棋譜保存と再生
- オンライン対戦

## 10. 技術上の課題

- オセロの合法手、反転、パス、終局を正確に処理する
- 3段階の強さに明確な違いを持たせる
- 手加減のための意図的なミスを、不自然に見せない
- 局面評価と最大の悪手の判定に納得感を持たせる
- AIの煽りと実際の盤面評価を一致させる
- WebGLでPC・スマートフォンの両方に対応する
- 端末性能に合わせて探索時間を制限する
- 画面サイズや縦横比の違いに対応する
